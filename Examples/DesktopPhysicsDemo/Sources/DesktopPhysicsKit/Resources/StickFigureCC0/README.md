# Stick Figure Character Sprites 2D

Selected animation frames from **Animated Stick Figure Character 2D Free
CC0**, created by Raphael Gonçalves (`rgsdev`).

Source: https://opengameart.org/content/animated-stick-figure-character-2d-free-cc0

Included sequences: idle, walk, run, jump, wall slide, and one slide frame used
as the seated pose. The source artwork is licensed under CC0; attribution is
not required, but the source and original license are retained here for
provenance. The PNG frames are otherwise unmodified.
